# Milton BPSC Tracker

Browser-storage BPSC syllabus tracker for GitHub Pages.

## Run locally

Open `index.html` in a browser, or serve this folder with any static server.

## Publish on GitHub Pages

1. Create a GitHub repository.
2. Upload `index.html`, `styles.css`, `app.js`, and this README.
3. In **Settings → Pages**, select the main branch and the root folder.
4. Open the generated Pages URL.

The app uses `localStorage`, so each browser/device has its own progress. Use **Export backup** before changing devices, then use **Import backup** to restore it.

The Admin portal is intentionally local because GitHub Pages has no server-side authentication. It lets you add, edit, and delete topics in the current browser.
